# Formato do GLOSSARIO.md

O `GLOSSARIO.md` é a linguagem oficial desta pasta de estudo. Todas as explicações, exercícios e registros de aprendizado devem seguir a terminologia dele. Montá-lo faz parte do aprendizado: comprimir um conceito numa definição enxuta é prova de que o usuário entendeu.

## Estrutura

```md
# Glossário de {Assunto}

{Uma ou duas frases descrevendo o assunto que este glossário cobre.}

## Termos

**Margem de contribuição**:
O que sobra de cada venda depois de descontar os custos que variam com ela (matéria-prima, comissão, imposto sobre a venda).
_Evite_: lucro da venda, ganho

**Ponto de equilíbrio**:
O valor de vendas em que a receita cobre todos os custos, sem lucro nem prejuízo.
_Evite_: empatar, ficar no zero a zero

**CAC (Custo de Aquisição de Cliente)**:
Quanto a empresa gasta, em média, para conquistar um cliente novo.
_Evite_: custo de marketing, gasto com anúncio
```

## Regras

- **Adicione um termo só quando o usuário o entender.** O glossário é um registro de conhecimento comprimido, não um dicionário para aprender. Se o usuário acabou de conhecer um conceito, espere até ele conseguir usá-lo corretamente antes de promovê-lo para cá.
- **Tenha opinião.** Quando existem várias palavras para o mesmo conceito, escolha a melhor e liste as outras como apelidos a evitar. É assim que a linguagem se comprime.
- **Mantenha as definições enxutas.** Uma ou duas frases. Defina o que o termo É, não o que ele faz nem como fazer.
- **Use os termos do glossário dentro das definições.** Depois que um termo entra, prefira-o em todo lugar, inclusive dentro de outras definições. É isso que torna termos complexos mais fáceis de entender depois.
- **Agrupe por subtítulos** quando surgirem grupos naturais (por exemplo `## Finanças`, `## Vendas`). Uma lista simples serve quando os termos combinam entre si.
- **Aponte ambiguidades.** Se um termo é usado de forma solta na área, registre a decisão: "Nesta pasta, 'cliente' sempre significa quem já comprou; quem ainda não comprou é 'lead'."
- **Revise conforme o entendimento cresce.** Uma definição escrita na primeira semana pode estar errada na sexta. Atualize no lugar, sem deixar entradas desatualizadas.
