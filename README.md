# Habilidades

Skills para o Claude em português do Brasil, feitas para donos de negócio e para quem trabalha com eles. Você não precisa saber programar nem entender como a IA funciona por dentro.

> Projeto em construção. As skills abaixo estão sendo traduzidas e adaptadas, uma por uma.

## Instalação

No Claude Code:

```bash
claude plugin marketplace add lucas-sachet/skills
claude plugin install habilidades@lucas-sachet
```
